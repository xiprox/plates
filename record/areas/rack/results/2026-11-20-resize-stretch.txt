The rack's window during a task list's open and close animations, from a screen recording
the user made on macOS 26.5.2, 2026-11-20, of Plates built from the working tree that day. The
recording showed the user's own sessions, so it stays out of the repository, and this file keeps
only the numbers measured from it.

The recording is 606x876 pixels at one pixel per point, 366 frames over 9.68s, at 37.5 frames a
second on average. For each frame, a script read two columns of pixels:

  x 157, inside the rack's left padding, where only the rack's 1px border is lighter than the
  rack's background: the border's last row is the window's bottom edge.
  x 166, inside the tiles' left padding, where no text reaches: each run of rows in the tile
  color is a tile, and its first row is the tile's top.

Every tile is 60px tall with 6px under it, so the tops of the tiles below the first are 66px
apart in a frame drawn at the window's size. A frame whose gaps differ from 66px by 2px or more
was drawn for one height and shown at another.

Frames 1 and 289 are left out: the first tile's open list split its run at x 166 in frame 1, and
in frame 289 the window's top read as row 5, so something other than the rack crossed the column
(unverified what).
